# 使用指南

**简体中文** | [English](usage.en.md) · [返回 README](../README.md)

## 首次使用与语言

安装并重启 Codex Desktop 后，在 Telegram 发送 `/help`。界面默认中文，不跟随手机或 Telegram 客户端语言自动切换。

- `/settings` → **语言**：显示中文 / English 选择按钮。
- `/language en`：切换英文。
- `/language zh`：切回中文。

选择保存在当前机器人数据目录的 `telegram_language.json`，服务重启和升级后保留。命令菜单、后续任务卡片、通知标题、按钮、提问提示及内置截图插件使用所选语言。已发送消息不批量重写；重新打开或刷新卡片可获取新语言。Telegram 菜单可能需要稍后刷新。

任务标题、文件路径、用户输入、Codex 答复和模型生成的问题/选项保持原文；语言切换不要求模型翻译，也不改变任务归属或提交内容。第三方插件需要提供自己的双语文案；底层服务错误和开发日志可能保留原文。

每个机器人配置一个接收聊天，语言偏好属于该机器人数据目录；授权群聊中的成员共享同一界面语言。切换仍受现有聊天及发送者授权限制。

## 查找任务与继续对话

1. 在正确的 Codex Desktop 环境中打开任务。
2. 发送 `/tasks` 浏览任务，或 `/running` 查看当前运行的任务。按钮可打开详情、进度、Diff 和用量。
3. 直接使用 Telegram 的“回复”回复任务通知、详情或进度卡片，即可向关联任务发送文字；也可附带图片或文件。
4. 或发送 `/send`，选择任务，收到提示后输入下一条指令。也可使用 `/send ID 消息`。

普通文字不会自动选中最近任务。没有任务关联时，机器人要求先选择任务；旧消息关联不存在时先打开对应任务详情。

直接回复运行中的任务时，会提示选择：

- **不打断，追加消息**：追加到当前任务。
- **中断当前 Turn 并发送**：仅在 Desktop 提供可验证的中止能力时可用。
- **侧边聊天**：独立只读问答，不打断主任务。
- **取消**：不提交这条消息。

`/steer` 用于追加运行中任务，`/stop` 用于请求中止当前可控制的任务。机器人不会为解决连接失败而接管原 Desktop 任务或改用 VS Code。

## 问题、审批与附件

Codex 提问会显示选项或文字回答入口。异步问题可以通过选项、文字入口或直接回复问题卡片回答，答案关联原问题和 Turn。过期或已回答的问题不可重复提交；复杂或不支持的审批需回 Desktop 处理。

任务卡片与问题卡片的直接回复属于不同操作：前者继续任务，后者回答那一个问题。任务运行状态不会因“已收到”而等同于提交成功；若提示提交结果未知，先检查 Desktop 最近消息，避免重复执行。

附件应通过回复任务或侧边消息发送，单个上限 20 MB；多个附件分次发送。完整答复可分页阅读或下载 Markdown。原文和 JSON 不会因为切换界面语言而被翻译或按 `suggestion` 字段过滤。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `/quota` | 查看剩余额度、提醒及重置卡 |
| `/tasks` | 浏览最近任务 |
| `/running` | 查看运行任务 |
| `/task [ID]` | 查看任务详情 |
| `/watch [ID]` | 跟踪任务进度 |
| `/diff [ID]` | 查看文件修改 |
| `/usage [ID]` | 查看任务用量 |
| `/help` | 查看使用帮助 |
| `/settings` | 调整静默模式、通知、语言和新任务目录 |
| `/logs` | 查看服务日志 |
| `/side [ID] <问题>` | 发起侧边提问 |
| `/send [ID] [消息]` | 发送任务消息 |
| `/steer [ID] [消息]` | 追加运行指令 |
| `/new <需求>` | 创建新任务 |
| `/stop [ID]` | 中止运行任务 |
| `/plugins` | [插件] 查看插件状态 |
| `/screenshot` | [插件] 截取窗口与屏幕（内置插件） |

菜单按“常用查询 → 帮助与设置 → 日志 → 发送和运行操作 → 插件”排列。额度查询固定第一项；插件入口及插件命令固定在底部，说明带 `[插件]` 标记；Telegram 最多显示 100 条命令，超出的插件命令仍可直接输入。

`/settings` 集中管理完成通知（原静音）、子代理通知、界面语言和新任务目录。打开设置不改变配置；开启／关闭按钮设置明确状态，重复点击不会反向切换。工作目录可用 `/settings cwd 绝对路径` 修改，支持路径中的空格，仅影响之后新建的任务。

`/language [zh|en]`、`/mute`、`/unmute`、`/subagents [on|off]`、`/cwd [绝对路径]` 及旧消息按钮继续可用，但不再单独占用菜单。`/help` 只显示帮助；取消待输入请使用原提示中的取消按钮。

多数任务命令省略 ID 时可使用按钮选择。`/help` 不改变待输入状态或额度预约。完整参数和额度规则见 [README](../README.md)。

## 静默模式

入口：`/settings` → **🌙 静默模式** → **开启静默**。默认关闭，选择会在重启和升级后保留。

- 保留额度、任务列表、运行任务、任务详情、Diff、用量、日志、插件状态及设置查询；主动查看历史回复仍可使用。
- 禁用普通回复、附件、`/send`、`/steer`、`/new`、`/side`、`/stop`、`/watch`、问题/审批作答、插件执行和额度重置。旧按钮同样受限制。
- 暂停 Codex 回复、提问、审批、进度以及其他自动推送；已有任务继续运行，不自动中止或代为批准。开启时取消进度跟踪和未执行的额度预约。
- 关闭静默后不会补发期间被抑制的回复，也不会恢复已取消的跟踪或预约。开启前已提交的请求无法撤回。

静默模式与“关闭完成通知”相互独立：前者限制为查询和设置，后者只调整通知开关。切换静默不会覆盖原通知偏好；它也不同于 Telegram 的免打扰/无声通知。

## 侧边聊天和插件

回复主任务消息发送 `/side 问题`，或使用 `/side ID 问题`。回复侧边答复可继续该会话；空闲 3 小时或服务重启后失效。侧边会话不执行主任务修改，关闭时保留已有答复。

`/screenshot` 使用随包插件。macOS 需要录屏授权；Linux Wayland 需要桌面 Portal 确认。自定义插件是可信本地 Python 代码，详见 [插件 API](plugins.zh-CN.md)。

Desktop 用户消息请求的默认等待为 **10 秒**。若返回超时或提交结果未知，Robot 再进行最多 **10 秒**的本地回执核对：只认可本次提交后、同一任务内内容匹配的用户消息及明确的消息/回合 ID；追加到指定回合时还要求回合一致。核对成功按已接收处理，否则提示“提交结果未知”，保留待核对记录且不自动重发。Desktop 自身的内部超时可能更短，此设置不会修改 Desktop 程序。

## 脱敏通知诊断

完成通知有一条例外：去除首尾空白后，整条正文恰好为 `{"suggestions":[]}` 时直接跳过，不发送、不进入诊断采样。只做字符串相等校验，不解析或归一化 JSON；内部空格不同、非空数组、附加字段、代码块或带解释文字的回复均不因这条规则被过滤。日志以 `exact-empty-suggestions-literal` 标记，和来源识别分开。

遇到来源无法确认、正文呈 `suggestion` / `suggestions` 结构的通知时，Robot 仍按原规则转发，同时在机器人数据目录的 `telegram_notification_diagnostics.sqlite3` 保存结构化诊断样本。其他结构的答复和已确认来源的通知不采集。正常 JSON 答复若同样呈建议结构，也可能被采集结构信息，但仍照常转发。

记录包含字段类型、数组数量、字符串长度、已知来源枚举、来源数据库查询状态，以及最新输入是否包含已观察到的内部建议请求结构。不会保存回复/提示词正文、文件路径、凭据、完整任务 ID 或未知字段名。未知字段名以位置占位符替代；请求结构特征仅供排查，不用于过滤。

重复样本合并计数，最多保留 100 条；每次写入清理超过 7 天未出现的样本。诊断写入失败不会阻止通知。普通日志中的 `diagnostic_sample` 可关联样本；诊断文件仅保存在本机，不上传、不打包。当前阶段不会因为采集到样本而自动屏蔽消息，需核对实际样本后再完善来源识别。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 找不到持有任务的 Desktop | 在正确的 Desktop 实例中打开任务，检查 `CODEX_HOME` 是否匹配 |
| 提交结果未知 | 先查看 Desktop 最新消息；不要连续重发 |
| 命令菜单仍显示旧语言 | 稍后重新打开菜单或发送 `/language`；直接输入命令不依赖菜单 |
| 切换语言后旧卡片仍为中文 | 刷新或重新打开卡片；原答复保持原文 |
| 两台电脑轮流收消息或轮询冲突 | 每台运行中的机器人使用独立 Bot Token |
| 英文界面中问题正文或插件仍为中文 | 模型内容不自动翻译；第三方插件需要提供英文文案 |

安装与更新见 [安装指南](setup.zh-CN.md)，实机通信验证见 [测试指南](testing.zh-CN.md)。
